# 國中智慧排課系統｜特殊選才作品集

這個 repository 是國中智慧排課系統的公開作品集與證據頁。

- Constraint Programming
- OR-Tools CP-SAT

- Software Validation
- AI-assisted Development

## 我的角色

我主要負責問題定義、需求分析、規格設計、技術決策、測試、驗證與驗收；Codex / LLM 協助程式實作、重構、測試與文件整理。

> 核心問題：不只是「能不能排出課表」，而是「如何證明排出的課表可信」。

## 公開程式碼說明

`code_samples/` 中的程式碼是從完整開發專案整理出的代表性公開範例，已移除真實教師、班級、學校與其他校務資料。這些檔案用來呈現核心建模、獨立驗證與反例測試的設計方式；完整開發 repository 目前維持非公開。
